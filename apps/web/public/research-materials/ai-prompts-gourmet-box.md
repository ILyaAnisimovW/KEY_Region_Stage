# Промпты ИИ для Gourmet Box

Примеры коротких запросов для дизайна, презентации и анализа. Выводы ИИ требуют сверки с проектом и первичными данными.

1. **Дизайн карточки:** «Предложи минималистичную карточку бокса: фото, состав, аллергены, срок, цена и время выдачи. Без лишних элементов».
2. **Мобильный экран:** «Собери компактную структуру главной страницы для телефона. Главные действия: открыть каталог и забронировать бокс».
3. **Доступность:** «Проверь контраст, размер текста и перенос длинных русских слов на экране шириной 320–390 px».
4. **Путь покупателя:** «Опиши пять шагов от просмотра бокса до выдачи по коду; для каждого назови возможное затруднение».
5. **Презентация:** «Сократи этот слайд до одного вывода и трёх подтверждающих фактов. Сохрани оговорки об ограничениях данных».
6. **Визуальная структура:** «Предложи сетку слайда 16:9 для сравнения расчётной модели и фото полевого исследования».
7. **Формулировки:** «Перепиши заголовки слайдов простым русским языком, без неподтверждённых обещаний и рекламных штампов».
8. **Анализ анкет:** «Сгруппируй открытые ответы по темам. Для каждой темы покажи номера анкет и короткие дословные цитаты».
9. **Проверка чисел:** «Пересчитай доли для опроса из 30 ответов и отметь, где вывод нельзя переносить на весь рынок».
10. **Экономика пилота:** «Проверь арифметику сценариев при 2, 3 и 4 боксах в день на точку. Отдели допущения от измеренных результатов».
