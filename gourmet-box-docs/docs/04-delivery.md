# Реализация и приёмка

## Этапы

1. Схема PostgreSQL, миграции, demo-пользователи, memberships, JWT и проверки ownership.
2. Партии, черновики, расчёт цены, публикация и каталог.
3. Брони и конкурентный резерв, выдача, отмена, неявка, закрытие.
4. История, SQL аналитика, интерфейсы и документация.

OpenAPI — источник HTTP-контракта. Генерируем типы клиента и проверяем соответствие ответов схемам, а не ведём отдельные ручные интерфейсы. Сначала достаточно одного backend и одной БД.

## Проверки перед сдачей

| Сценарий | Ожидаемый результат |
|---|---|
| Полный demo-цикл | Выданный заказ, корректное списание и запись в истории |
| 20 одновременных броней последнего бокса | Одна успешная бронь, остальные 409; баланс неотрицателен |
| Два бокса используют одну партию | Общая публикация не выделяет больше свободных единиц |
| Повтор POST с тем же ключом | Тот же ответ, одно событие и одно движение |
| Повтор ключа с другим телом | 409 IDEMPOTENCY_CONFLICT |
| Изменение черновика после quote | Публикация со старым quote отклонена |
| Истёкшие сроки или неподтверждённое хранение | Публикация запрещена |
| pickupAt вне окна или менее чем через 15 минут | 422 |
| Неявка раньше допустимого времени | 422; резерв сохранён |
| Неявка открытого бокса | Резерв снят, допустимая повторная бронь доступна |
| Закрытие с активной бронью и последующая неявка | Свободные продукты освобождены один раз, зарезервированные — при неявке |
| Одновременные выдача и отмена | Один конечный переход, одна корректная проводка |
| Неверный код выдачи | Выдача не произошла; после лимита попыток 429 |
| Покупатель запрашивает чужой заказ | 404; нет утечки кода и истории |
| Сотрудник другого заведения | Нет доступа к изменениям, заказам и аналитике |
| Worker остановлен | Просроченные боксы не бронируются через API |
| Любой выбор оплаты | NOT_PROCESSED, деньги не списываются |
| Аналитика при нулевом знаменателе | noShowRate = null |
| Граница суток и from/to | UTC-фильтрация [from,to), группировка в timezone заведения |

## Демоданные

Заведение Europe/Samara; партия A: 20 круассанов по 15 000 коп.; партия B: 10 сэндвичей по 25 000 коп. Бокс: 2 A + 1 B, исходная цена 55 000 коп., 5 боксов. При остатке до ближайшего предела 5 часов скидка 50%, цена 27 500 коп. Публикация выделяет 10 A + 5 B. Бронь двух боксов оставляет 3 доступных; выдача списывает 4 A + 2 B. Аналитика: 1 выданный заказ, 2 бокса, стоимость 55 000 коп., исходная стоимость 110 000 коп., скидка 55 000 коп.

Абсолютные даты seed генерировать относительно текущего времени, чтобы demo не устаревало. Окно должно удовлетворять всем правилам срока и получения.

## После MVP

Платёжный провайдер потребует отдельной сущности Payment, идемпотентного webhook, проверки подписи, возвратов и согласования срока платёжного резерва. NOT_PROCESSED нельзя переименовать в PAID без подтверждённой операции. Затем можно добавить уведомления, коррекцию ошибочных статусов и интеграции склада.
