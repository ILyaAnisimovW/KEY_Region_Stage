# Gourmet Box — MVP 1.0

Сервис реализации непроданных остатков заведений через боксы с фиксированным составом.

Путь пользователя: остатки → проверка и скидка → публикация → бронь на выбранное время → выдача → история и аналитика.

Это проект требований и архитектуры, а не действующее приложение. Онлайн-оплата отложена: оба способа оплаты работают как заглушки.

2. [Архитектура C4](02-architecture.md) — где выполняется логика и почему выбран монолит.
3. [Данные и транзакции](03-data-and-flows.md) — как избежать перепродажи и двойного списания.
4. [Приёмка](04-delivery.md) — как проверить реализацию.
5. [Публикация](05-documentation.md) — как поддерживать отдельный сайт документации.
6. [API-справочник](api.html) — генерируется из [OpenAPI](openapi.yaml).
